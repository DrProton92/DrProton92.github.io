[Open Monte Carlo Retirement Simulation](https://polite-mushroom-081e2b310.2.azurestaticapps.net/)

This interactive web application explores how retirement savings could change under different market conditions. Set an age range, enter income and expenses, and adjust starting savings and market assumptions to compare simulated outcomes.

## Income, expenses, and withdrawals

Add income sources and expense categories with monthly, quarterly, or annual amounts and the ages when they apply. Charts show income, expenses, and the withdrawals needed from retirement savings over time.

## Explore market uncertainty

Adjust the average annual return above inflation, return variability, and number of scenarios. Run the simulation to compare market returns and savings paths, and see the percentage of simulated scenarios in which savings last throughout the selected period.

The application saves inputs in the browser so a scenario can be revisited and adjusted.
